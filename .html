Project Workflow

01

Hand Tracking

MediaPipe locates and tracks 21 hand landmarks per frame in real time.

02

Data Collection

Landmark coordinates are captured and labeled for each gesture class.

03

Model Training

A deep-learning model learns to classify gestures from landmark data.

04

Real-Time Detection

The trained model predicts gestures live and triggers text + speech output.

AI & Machine Learning Frameworks

MediaPipe

Real-time hand landmark detection & tracking

TensorFlow / Keras

Deep-learning model for gesture classification

OpenCV

Video capture and image processing

scikit-learn

Data preprocessing and evaluation metrics

gTTS / pyttsx3

Converts recognized gestures into spoken audio

Streamlit

Interactive UI for demoing the model
