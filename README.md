# ISL Real-Time Translator

Real-Time Indian Sign Language Recognition & Translation Engine using Deep Learning, TensorFlow, and MediaPipe.

## Prerequisites
Make sure you have **Python 3.11** installed on your laptop before proceeding.

## How to Run This Project on Your Laptop

Follow these step-by-step instructions in your terminal (Command Prompt or VS Code terminal) to set up the environment and run the real-time detector:

### 1. Clone the Repository
```bash
git clone [https://github.com/piyush25bai11629-ui/ISL-RealTime-Translator.git](https://github.com/piyush25bai11629-ui/ISL-RealTime-Translator.git)
cd ISL-RealTime-Translator
